Export

Export writes PNG, JPEG, WebP, TIFF, TGA, OpenEXR, PDF, SVG, and layered Photoshop files at a chosen size and quality, from the same code that draws the preview. A smaller export is evaluated at its own size rather than shrunk from a full-size one, and batches run from the app, the command line, or a node graph.
