ImageGui user guide

This guide walks through ImageGui by task: opening a picture, adjusting it, working with layers, text, and shapes, selecting and masking, retouching, changing its geometry, and exporting it. The pictures come from the feature gallery, which the test harness takes screenshots of the running application on every build of main, so they show the shell as it is today.

Every edit in ImageGui is non-destructive. Adjustments, crops, turns, and masks are recorded as steps on top of your original files, which are never changed, and every step can be undone, edited later, or switched off.

Opening pictures and projects

File > Open (Ctrl+O) opens a PNG, JPEG, WebP, or TIFF image, a Photoshop file (.psd or .psb), or an .imagegui project. You can also name one when starting ImageGui (ImageGui photo.jpg). With nothing open, the canvas shows a start screen in its middle: New, Open, a reminder that you can drop files onto the window, and your recent files as a grid of thumbnails with each file’s name and folder under it.

File > New (Ctrl+N) makes a blank canvas: type a size or pick one of the screen, print, and square presets, over white, black, a colour, or nothing at all. A coloured background is an ordinary fill layer named Background, so it can be recoloured or deleted later.

TIFF files from scanners and other editors open whether uncompressed or LZW, Deflate, or PackBits compressed, at 8 or 16 bits, in colour or greyscale, with or without transparency.

Photoshop files open with their layers: names, groups and pass-through, visibility, opacity, clipping, blend modes, and layer masks all come across, and each layer’s pixels are kept inside the project. Text, smart objects, and fill layers arrive as the pixels Photoshop last drew for them, renamed to say so. An Invert, Levels, or Exposure adjustment layer becomes the same adjustment here; other adjustment layers are left out. A file with 16 or 32 bits a channel comes across with 8, and the list says so. Whatever didn’t come across exactly is listed once the file opens. File > Place takes a Photoshop file too, and adds its layers as one group.

Edit > Paste as New Layer (Ctrl+V) adds the image on the system clipboard as a layer at its own size, in the middle of the canvas, or opens it as a new picture when nothing is open. Edit > Copy Merged puts what the canvas shows on the clipboard, every layer together, cut to the selection when there is one.

Photos open the way they were taken: a picture the camera stored sideways is turned upright, and a wide-gamut colour profile such as Display P3 is converted to sRGB.

File > Open Recent lists recent files with a thumbnail of each one beside it. A project carries its own; an image is decoded small for one.

A project links to its original images rather than copying them. If one has moved, ImageGui asks where it went, or opens the project without it so you can point the layer at its file later with Layer > Relink Image. Once one file is found, others from the same folder are offered too.

If ImageGui stops without saving, the next start offers your unsaved work back.

If ImageGui ever closes because of an error, it also writes a report to a dated file in its data folder (ImageGui/Crashes under your local application data folder): the error, the versions in use, the picture’s size and layer count, and the names of the last steps you took. It holds no pixels and no folder names, and nothing is ever sent anywhere. The next launch says so once and offers to open the folder or copy the report, so you can share it if you want to report the problem.

ImageGui starts on the start screen. To pick up where you left off instead, choose Reopen what was open under On launch in Preferences: the project or picture that was open when ImageGui last closed opens again at the zoom and scroll you left it at. A file named when starting ImageGui, or one opened from the file manager, comes first, and unsaved work from a crash is offered back as above rather than reopened silently.

Looking at the picture

View > Zoom In (Ctrl+=) and Zoom Out (Ctrl+-) step through fixed scales; Fit, 50%, 100%, and 200% jump straight to one. Scrolling over the canvas zooms too.

The status bar under the canvas shows the picture’s name, with a * while it has unsaved changes, its size in pixels, the zoom, the pointer’s position in the picture’s own pixels, and a one-line hint for the chosen tool. Click the zoom for a list of presets, or type a percentage such as 150 and press Enter.

While you work, the canvas shows a preview of the picture held to the Preview size set in Preferences, so edits stay quick on large pictures. Zoomed in past that preview’s own pixels, the canvas renders just the part you can see at the screen’s scale, up to the picture’s own pixels, as soon as you stop panning or zooming. While you drag, the last render stays where it belongs and the enlarged preview fills in around it. A few adjustments, such as lens correction, need the whole picture to render any part of it; on a picture too large to render whole at that size, the canvas keeps the enlarged preview and shows a Preview badge in its corner. Exports always use the full picture.

From 600% each pixel is drawn as a flat square, and View > Pixel Grid draws a line around each.

The View menu also opens these panels:

  • Navigator: the whole picture small, with a rectangle you drag to pan.
  • Info: the position and colour under the pointer, and while you edit an adjustment, the colour entering and leaving it.
  • Histogram: the finished picture’s histogram, per channel or luminance, with clipping, for the whole picture or the selection only. Pick the channel from the tabs along its top, as in levels and curves. The graph grows with the window, so drag its edge for a larger one.
  • Show Clipping (Shift+J): tints the canvas where the picture has clipped, blue where every channel is black and red where any channel is at white. It only marks the screen, never the picture, and follows drags live. Clicking either clipping readout in the histogram turns it on or off, and Preferences can widen its thresholds to warn of pixels that are nearly clipped.
  • History: every edit by name (see Undo and history).
  • Before/After: compare with the picture before its adjustments and effects, alone, side by side, or split by a divider. Backslash (\) toggles it.
  • Rotate View (R): turn the canvas on screen, as a painter turns the paper, without changing the picture. Drag round the canvas to turn it; hold Shift to turn in 15° steps. Double-click or press Esc to put it upright, or choose Reset Rotation. The status bar’s zoom shows the angle, and every tool, guide, and readout follows the turn.
  • Proof: show the canvas as seen with protanopia, deuteranopia, or tritanopia, or as greyscale, to check that text and graphics don’t rely on colours only some people can tell apart. It changes only what the canvas shows: a badge marks it while it’s on, and exports are untouched.
  • Rulers: pixel rulers to drag guides out of. Dragged layers snap to guides, and Snap turns snapping off.

Notes on the canvas

Notes are reminders pinned to a spot on the picture, such as “fix this edge” or “client wants warmer”. Choose the Note tool (N), click where the note belongs, type it, and press Enter; Ctrl+Enter starts a new line, and Escape drops it. Each note is a numbered pin. Hover a pin to read its note, click it to edit or delete it, and drag it to move it.

View > Notes lists every note by its first line. Click one to highlight its pin and edit its text below the list. View > Show Notes hides or shows the pins; the Note tool shows them while it is chosen. Notes are saved with the project and move with the picture through crops, turns, and Canvas Size, but they are never drawn into the picture, so no export has them in it.

Adjusting colour and tone

Select a layer and choose from Add adjustment in the inspector. Adjustments stack, and each applies to the result of the ones before it. Move one up or down with its arrow buttons, switch it off without losing its settings, or remove it.

The adjustments available are exposure, brightness/contrast, saturation/vibrance, black and white, levels, curves, white balance, HSL, colour balance, colour grading, channel mixer, selective colour, sharpen, Gaussian blur, clarity, vignette, noise reduction, dehaze, lens correction, invert, posterize, threshold, gradient map, and photo filter.

Levels and curves are drawn on the histogram of the pixels reaching them, as wide as the panel, and both have a tab for each color channel as well as the composite. The curve sits in a square box, so its diagonal stays at 45 degrees. Pick black point and Pick white point set levels from a click on something that should be black or white.

Levels, curves, and white balance each have an Auto button that sets them from the histogram, as one undo step you can carry on editing. White balance takes a grey-world estimate of the light, levels sets each channel’s black and white points so a tenth of a percent clips at either end, and curves draws a stretch between the darkest and brightest tenth of a percent with a gentle S.

White balance and HSL can be set by clicking on the canvas: Pick neutral point balances on something that should be grey, and Pick color on canvas finds the HSL band under the pointer, which you then drag left or right to adjust.

Colour grading has a wheel each for the shadows, midtones, and highlights, and a global wheel for the whole picture. Push a wheel’s handle towards the colour to add; how far from the centre is how strong the tint is, and the slider under the wheel brightens or darkens that range. Double-click the wheel or its slider to reset it. Blending sets how far the ranges overlap, and Balance leans them towards the shadows or the highlights.

Channel mixer rebuilds each output channel from red, green, and blue plus a constant, on a tab per channel. Its total turns amber when a row strays from 100%, since above that the channel brightens. Monochrome mixes one grey for all three. Selective colour adds or takes away cyan, magenta, yellow, and black in one family of colours at a time, from reds to blacks: Relative scales each change by the ink already there, and Absolute adds it outright.

Gaussian blur softens the whole layer, so a layer’s own edge feathers out without a dark fringe. Clarity is local contrast: it pushes each pixel away from the area around it, weighted to the midtones, and dragged left it softens instead. Both measure their radius against the layer’s height, so the preview shows what the export will.

Noise reduction smooths grain in lightness while keeping edges, and Detail puts some texture back; Color smooths colour blotches. Dehaze takes out haze, clearing distant hills and deepening the sky; dragged left, it adds haze instead.

Lens correction removes barrel or pincushion distortion, the red/cyan and blue/yellow fringes towards the corners, and the darkening a lens leaves in them, centred on the layer. Correcting barrel distortion pulls the middle of each side in and leaves transparent edges; Auto Scale enlarges the picture just enough to crop them away.

Fading and blending an adjustment

Under each adjustment’s name are its Blend mode and its Opacity. Lowering the opacity fades the adjustment towards the pixels it was given, so a black and white at 60% leaves some colour in. A blend mode combines the adjustment’s result with its input the way a layer’s mode combines it with what is below: Luminosity changes brightness without shifting colour, Color changes colour and keeps brightness, and a neutral adjustment in Multiply, Screen, or Soft Light darkens, lightens, or adds contrast on its own. A mask has only an opacity, which fades how much of it applies.

Reusing adjustments

Edit > Copy Adjustments (Ctrl+Shift+C) copies the selected layer’s stack, and the copy button on an adjustment copies just that one. Paste Adjustments (Ctrl+Shift+V) adds them to every selected layer.

To keep a stack for later, or for other pictures, save it with Layer > Adjustment Presets > Save Stack as Preset, or right-click one adjustment and Save as Preset. Presets apply from the same menu or from the inspector’s Presets list. Saving a whole stack can include the layer’s effects too; applying such a preset replaces each layer’s effects with them.

Layers

A document is a tree of layers and groups, listed top first in the Layers panel. Click a row to select it, Ctrl+click to select several, double-click to rename, and drag to reorder or drop into a group. Every panel acts on the selected layer.

From the Layer menu:

  • Add Image Layer places another picture on the canvas; Add Text Layer (Ctrl+Shift+T) adds text; New Fill Layer adds a solid colour, a gradient, or a pattern.
  • New Group (Ctrl+Shift+N), Group (Ctrl+G), and Ungroup (Ctrl+Shift+G). Ungrouping keeps the picture: the group’s position, perspective, and visibility go onto each layer in it, and a group holding one layer hands that layer its blend mode, opacity, effects, and adjustments too. When something can’t be moved exactly, such as a mesh warp or an adjustment over several layers, Ungroup is unavailable and its tooltip says what would be lost.
  • Duplicate (Ctrl+J), Delete (Delete), Move Up (Ctrl+]), and Move Down (Ctrl+[).
  • Clip to Layer Below (Ctrl+Alt+G) shows a layer only where the one beneath it is.
  • Align and Distribute line layers up with the canvas or each other.
  • Rasterize turns a text layer into an image layer that looks the same, Merge Down (Ctrl+E) merges a layer into the one beneath it, and Flatten Image leaves one layer of what the canvas shows. The result’s pixels are kept inside the project, and undo brings back the layers they replaced. The first time, each says what it will lose before it runs: anything reaching past the canvas, hidden layers, and colour finer than 8 bits a channel, since the new layer is stored that way. Don’t ask again stops the question; File > Preferences > Ask before Rasterize, Merge Down and Flatten Image brings it back.

Every color is edited in one compact field: a swatch and its hex code on one row. Click the swatch to open its popup, which holds:

  • a picker, with an alpha bar where the color has one;
  • a hex box, which takes #RGB, #RRGGBB, or #RRGGBBAA when you press Enter or click away;
  • Pick, an eyedropper: click the canvas and the field takes the color shown there. Esc cancels;
  • the recently chosen colors and the swatch palette, the same in every field. Click either to set the color; + adds the current color to the swatches, - removes it, and a swatch can be dragged to reorder it. Both are kept between runs.

Fields for text, fills, shapes, gradient stops, effects, photo filter, text styles, and New Document all work this way. A hex code, a canvas pick, or a swatch is one undo step each.

Pattern fills

A fill layer whose Type is Pattern repeats an image across itself. Each document keeps its own patterns, saved inside the project, and the inspector’s Pattern list picks one. Load Pattern… adds an image file and fills with it, and Edit > Define Pattern adds what the canvas shows: the selection’s contents, with anything outside a feathered or shaped selection left transparent, or the whole canvas with no selection. Layer > New Fill Layer > Pattern fills with the newest one, and the Pattern overlay effect tiles the same patterns over any layer.

A tile is laid at its own pixel size, starting from the layer’s top-left corner. Scale sizes it, Angle turns it, and Offset shifts it in canvas pixels. Moving the layer moves the pattern with it, while resizing the layer only shows more or less of it.

A row’s right-click menu also tags layers with a colour Label.

Placing a project

File > Place… takes an .imagegui project as well as an image. An image becomes an image layer at its own pixel size. A project asks whether to Embed a copy of it in this project or Link to its file, and becomes a layer of its own at its canvas’s size. That layer is drawn by evaluating the whole placed project at the size it appears on the canvas, so its text and shapes stay sharp however far it is scaled, and like any layer it takes adjustments, effects, masks, blend modes, locks, and the Move tool’s transforms.

An embedded project is saved inside this one and never changes on its own. A linked project follows its file: when the file is saved again, by ImageGui or anything else, the layer takes in the new version as one undo step. A linked project whose file has moved opens with its edits and its shape kept, drawing nothing, and Layer > Relink Project… points it at the file wherever it is now. Save Packaged Copy carries linked projects’ files along, as it does images.

Layer > Edit Contents opens the selected placed project as the current document. This project is saved first, and saving the placed project brings you back to it with the change in place: a linked project is simply read again, and an embedded one takes in the edit as an undo step, leaving this project to save. File > Return to … goes back without saving, and saving the placed project under another name keeps it as a project of its own.

Finding a layer

Once a document has four or more layers and groups, the search box over the rows shows only the layers whose names contain what you type, and the Filter button beside it narrows them by kind (image, text, shape, fill, or group), colour label, visibility, or lock. A match inside a group shows with the groups around it, even folded ones, and nothing about the document changes: clear the box and the panel is as it was. Rows can’t be dragged to reorder while a filter is on.

With the Move tool, Ctrl-click the canvas (or Alt-right-click it) to select the topmost layer drawn there, or right-click to list every layer drawn there and choose one. Hidden layers, the transparent parts of a layer, and what its masks hide don’t count, and picking a layer inside a folded group unfolds the group so its row shows.

Locking layers

The padlock on a layer’s row locks it. Position stops it being moved, scaled, nudged, aligned, or straightened; Pixels stops adjustments, effects, masks, and text edits; All also locks its blend mode, opacity, and clipping. A group’s lock covers everything inside it. Whatever a lock refuses is greyed out, and its tooltip says which lock is in the way. Each change of lock is one undo step.

Blending and opacity

The Blend picker offers twenty-six modes, and the opacity slider fades a layer. A group normally blends its own layers together first; choose Pass Through at the top of its blend list to let each layer blend straight onto what is below the group.

Moving and scaling

With the Move tool (V), drag inside a selected layer’s outline to move it, a corner to scale it in proportion (Shift scales freely), or an edge to stretch it. The arrow keys nudge it a pixel at a time, or ten with Shift. Dragged layers snap to the canvas, other layers, and guides; hold Ctrl to drag freely.

Ctrl-drag an edge to skew the layer along it. Ctrl+Shift-drag a corner to move that corner alone and give the layer a perspective; once distorted, its corners move one at a time with a plain drag. Any layer can be distorted: text, fill, and shape layers are drawn in their own frame and then warped, so text stays editable and sharp, and a group’s perspective carries everything in it.

Warping

Edit > Transform > Warp lays a grid over the selected layer, in place of its transform box. Drag a point to pull the layer with it, or one of its handles to bend the lines either side of it, and the layer follows the grid as if it were printed on a sheet of rubber. The grid starts at three cells by three; the same menu offers four, five, or six, and changing the grid keeps the bend as nearly as the new grid can hold it. Press Enter or Escape, choose Warp again, or select another layer to put the box back; the bend stays. Remove Warp straightens the layer again.

Any layer can be warped. Images and placed projects are resampled through the grid with the document’s resampling filter; text, shapes, and fills bend their outlines, so they stay sharp at every size; a group bends everything in it. The warp is applied in the layer’s own frame, before its perspective and placement, so moving, scaling, or distorting a warped layer carries the bend with it. Each drag is one undo step. A position-locked layer can’t be warped, and a layer inside a warped group is warped with its group. Text is typed straight while it is edited on the canvas, and a warped shape can’t have its points edited or be combined until the warp is removed. A layer’s masks and limits are held in its frame before the warp, so they don’t bend with it.

Linking layers

Select two or more layers and choose Layer > Link Layers to have them move together without grouping them. Moving, scaling, skewing, distorting, nudging, or aligning any one of them moves the others by the same change on the canvas, wherever they sit in the layer tree. A chain icon at the right of each linked row shows which layers are linked; click it to select them all. Linking a layer to one that is already linked adds it to that link.

Layer > Unlink Layers takes the selected layers out of their link, and the rest stay linked, as they do when one of them is deleted. A linked layer whose position is locked keeps all of them in place, and the tooltip names it. Each link change is one undo step, and links are saved with the project.

Effects

The inspector’s Effects section adds a drop shadow, a stroke, an outer glow, an inner shadow, an inner glow, a colour overlay, a gradient overlay, a pattern overlay, a bevel and emboss, and a satin to any layer, each with its own blend mode. They follow the layer’s shape, so they work on text and groups too.

A stroke’s Position puts it outside the edge, inside it, or centred on it. The Colour overlay paints the layer one colour, and the Gradient overlay paints it with a gradient edited like a gradient fill’s, linear along an angle or radial, fitted to the layer’s pixels; Scale stretches it. The Pattern overlay tiles one of the document’s patterns over the layer from the corner of its pixels, so it moves with the layer, at a Scale and Angle of its own. It needs a pattern in the document first, and a preset leaves it behind, since patterns belong to a document. The Inner glow lights the layer from its edge inwards, or from its middle out. Overlays and inner glows lie inside the layer’s edge, over anything clipped to it.

Shadows follow the document’s light: Layer > Layer Effects > Global Light turns every shadow with Use global light ticked at once, in one undo step, and so does changing the angle of any one of them. Untick it to give a shadow an angle of its own. Effects pasted or applied from a preset take the document’s light too.

Bevel and emboss shades the layer’s edge as a slope lit from one side, so it looks carved. Its Style puts the slope inside the edge (Inner), outside it so the canvas rises to meet the layer (Outer), across it so the layer looks pressed up out of the canvas (Emboss), or down into the edge from both sides like a stamp (Pillow). Depth steepens the slope, Size widens it, Soften blurs the shading, and Direction raises or sinks it. The light has an Angle, which follows the global light like a shadow’s, and an Altitude above the canvas. The Highlight and Shadow each have their own colour, opacity, and blend mode.

Satin lays a silky sheen inside the layer: its own shape, softened by Size, moved by Distance both ways along an Angle, and laid where the two copies differ, or where they agree with Invert ticked, which is how it starts.

Layer > Layer Effects > Copy copies the selected layer’s effects, and Paste gives them to every selected layer in place of their own, as one undo step. Both are on a layer row’s right-click menu too. They are separate from copying adjustments, so each keeps what it holds. Pasted effects keep their size on the canvas: a 3 px stroke is 3 px on a small layer and a big one alike. The layer thumbnails show each layer with its effects.

Layer comps

View > Layer Comps keeps named layouts of the layers, so one project can hold several versions of a design. New saves which layers are shown, where each sits, its opacity, blend mode, and which of its effects are on; Apply (or a double click) goes back to the chosen comp in one undo step; Update replaces what it remembers with the layers as they are now; and the name field beside Rename and Delete manages the list. Layers deleted since a comp was saved are skipped, layers added since keep what they have, and a locked layer keeps what its locks protect. Pixels, adjustments, and text are the same in every comp. Export Animation can play the comps as the frames of a GIF or WebP.

Artboards

An artboard is a named rectangle of the canvas that exports as a picture of its own, so one project can hold every size of a social post or every icon of a set. Layer > New Artboard asks for a name, a size (type one, or pick a common social or icon size), and a background: white, black, a colour, or transparent. The first artboard takes the canvas, so the picture becomes the first of the set; each later one goes to the right of the last, and the canvas grows to hold it.

Whatever sits on an artboard belongs to it: a layer at the top of the stack belongs to the artboard its middle is in. Each artboard’s background is a fill layer at the bottom of the stack, named after it, so it can be recoloured or given a gradient in the Fill panel like any other fill. With the Move tool, drag an artboard’s name to move it and everything on it, or click the name to choose it and drag an edge or corner to resize it, which leaves what is on it where it is. Escape, or a click elsewhere on the canvas, goes back to the layers. Layer > Artboards lists them all, with their names, places and sizes in pixels and their background colours, each editable, and deletes them. Deleting an artboard deletes its background and leaves everything else on the canvas.

When a document has artboards, Export offers Each artboard, which writes every artboard beside the file you chose, named after it and the artboard (post-Story.png), rendered over its own rectangle alone. Export Layers offers Each artboard too, and a batch can write each artboard of every project in it. A document with no artboards exports exactly as before.

Text

Layer > Add Text Layer (Ctrl+Shift+T) adds a line of text. The inspector’s Text section sets what it says, the font, size, alignment, line spacing, and colour. Text stays sharp at any size, because it is drawn from the font’s outlines.

To type on the canvas, double-click a text layer, or choose the Text tool (T) and click it. Clicking where there is no text adds a new text layer. While editing, the arrows, Home, End, Ctrl+A, and the clipboard work as in any editor, a double click selects a word, a triple click a line, and dragging a selection moves it (Ctrl copies). Ctrl+Enter or a click elsewhere finishes; Escape puts the text back.

Wrap in a box turns a caption into a paragraph that wraps to a box you can resize.

A character the font has no glyph for, such as an emoji, a Chinese, Japanese, or Korean character, or a symbol, is drawn in the first installed font that has it instead of as an empty box: first the fonts the project carries, then the emoji, symbol, and CJK fonts each platform installs (Segoe UI Emoji and Symbol, Apple Symbols, the Noto families, DejaVu Sans, and others). The caret and wrapping measure it in that font, and Save as Package carries the fallback font along with the text’s own. Colour emoji fonts that hold only pictures are skipped, because text is drawn from outlines.

Select some of the text while editing it and a bar floats over it. Its first row sets the selection’s bold and italic faces (Ctrl+B, Ctrl+I), size, colour, and font. Its second row underlines it (Ctrl+U) or strikes it through, at the position and thickness the font gives; makes it superscript or subscript; loosens or tightens its tracking; and raises or lowers it off the baseline. Its third row aligns the paragraphs the selection touches left, centre, right, or justified, each paragraph on its own. Justify spreads every line of a boxed paragraph but its last across the box; the inspector’s Alignment sets every paragraph at once.

Leading and paragraphs, folded away under the inspector’s Text section, sets how far apart lines and paragraphs sit, all in ems of the text’s size:

  • Auto leading spaces lines by the line spacing times their largest size. Clear it to set the Leading, baseline to baseline, yourself. Leading belongs to characters, as size does, so a line takes the largest leading on it.
  • Before and After add space above and below a paragraph. The space before the first paragraph is left out, so the text still starts at the top of its box.
  • First line, Left, and Right indent a paragraph from the box’s edges. Below zero, the first line hangs out to the left of the rest, as far as the box’s edge.

While you edit the text on the canvas, these apply to the paragraphs your selection touches, or the caret’s paragraph, and leading to the selected characters or the caret’s paragraph; they drag rather than take typing, and using them doesn’t end the edit. Otherwise they apply to all of the text. Point text has no edges to indent from, so it takes leading only.

OpenType features, folded away below it, turns on the extras a font draws: Ligatures (on unless you turn them off) and Discretionary ligatures, Small caps, old-style or lining Figures, Tabular figures for columns of numbers, Fractions, Stylistic sets 1 to 20, and Kerning (on unless you turn it off). Only the features the text’s font has are listed. While you edit text on the canvas they apply to the selection, or the caret’s paragraph, without ending the edit; otherwise to all of the text, each switch one undo step. The caret still stops between the letters a ligature joins.

Vertical sets the text top to bottom, in columns that run from right to left, as Chinese, Japanese, and Korean are often set. Their characters stand upright; Latin letters and digits lie on their side, as HarfBuzz’s vertical shaping sets them. Once the text is vertical, Upright appears below the Path list and stands the selected characters (or, with nothing being edited, all of the text) upright too, which is how a sign spells a word down a column. Alignment runs down the columns: left sets them from the top, right to the bottom. Boxed vertical text wraps at the box’s height and adds columns to the left; columns that don’t fit the box’s width aren’t drawn. While you edit vertical text the caret lies across the column, Up and Down move along it, and Left and Right move to the next or previous column. Vertical text can’t follow a path.

When the text’s font is a variable font, Font axes, folded away above the OpenType features, has a slider for each of the font’s axes, such as weight, width, slant, and optical size, and Font’s default puts them all back. Like the features, the sliders apply to the selection while you edit on the canvas, otherwise to all of the text, and each drag is one undo step. A font that isn’t variable shows no axes.

Text styles

View > Text Styles keeps named styles in the document, so a heading or a caption looks the same wherever it is used:

  • A character style holds a font, size, colour, tracking, baseline shift, underline, strikethrough, OpenType features, Upright, and a variable font’s axes. It applies to characters.
  • A paragraph style holds alignment, space before and after, and indents. It applies to whole paragraphs.

New makes a style from the selected text and links the text to it. Clicking a style applies it: to the selected text layers, or, while you edit text on the canvas, to the selection (a character style) or the paragraphs it touches (a paragraph style). Using the panel doesn’t end the edit.

Choose a style to edit it below the list. A change, or Redefine, which takes the selected text’s values into the style, updates every text linked to it, in one undo step. Text you changed by hand keeps that change: if a linked word is struck through and the style isn’t, it stays struck through when the style changes. A + beside a style’s name means the selected text is linked to it but differs from it; clicking the style again clears the differences. Delete removes a style and leaves its text looking as it did.

Styles are saved in the project. Text copied on the canvas and pasted into another document brings the styles it uses, joining a style of the same name there if it has one; undoing the paste removes them again.

Layer > Warp Text, or Warp in the inspector’s Text section, bends a text layer into an arc, arch, bulge, flag, wave, fish, rise, or squeeze. Each starts at a bend of 50%; the inspector’s Bend, Horizontal, and Vertical distortion sliders (-100% to 100%) adjust it, and None straightens it again. The warp bends the text’s outline rather than its pixels, so the text stays editable and sharp at any size, and moving, scaling, and distorting the layer work on the warped text. While you edit warped text on the canvas it is shown straight, so the caret sits on the letters; it bends again when you finish. A warped paragraph’s handles scale it rather than resize its box.

Text on a path

Text can follow a path instead of a straight line. With the Text tool, click a path drawn with the Pen, or a line, ellipse, or rectangle, and type: the text starts where you clicked. To put existing text on a path, select it and choose Layer > Attach Text to Path, or pick the path from Path in the inspector’s Text section. Each letter stands upright on the path, turned to its direction, and an underline or strikethrough bends along it. An ellipse’s path runs from its left over the top, so text on a circle reads upright across its top.

The text’s Alignment says whether the line starts, centres, or ends at its place on the path, and Position moves that place along the path (0% is the path’s start, 100% its end). Flip runs the text the other way, on the path’s other side. Text longer than an open path carries straight on past its end; round a closed one it wraps.

The text follows its path layer: edit the path’s points, or move, scale, or rotate the layer, and the text goes with it. While you edit text on a path on the canvas, the caret and selection travel along the path. Text on a path can’t be warped or wrapped in a box; Layer > Detach Text from Path, or None in the Path list, sets it straight again. If you delete the path layer, the text keeps the path where it last was, in the same step, so undoing the delete puts both back.

Shapes

The Shape tool (U) draws a rectangle, rounded rectangle, ellipse, line, polygon, or star as a layer of its own. Press U again to move to the next shape, or pick one from the strip beside the tools, which also sets the fill, the stroke, the corner radius, the polygon’s number of sides, and the star’s points and inner radius for the next shape you draw. Hold Shift to draw a square or a circle, or to keep a line to 45 degrees; hold Alt to draw out from the centre. Layer > New Shape adds one in the middle of the picture instead.

A shape is drawn from its outline, so it stays sharp however far you scale it. The inspector’s Shape section changes its fill (a colour or none) and stroke (a colour and a width, or none) afterwards, and the Move tool’s box moves, scales, rotates, and skews it like any other layer. Shapes take adjustments, masks, blend modes, opacity, clipping, effects, and locks too. Select > From Shape turns the selected shape’s outline into a selection.

Dashes, caps, and joins

Once a shape is stroked, the inspector’s Shape section also styles the stroke. Dashes breaks it up: the presets (Dashed, Long dashes, Dotted, Dash dot) are worked out from the stroke’s width when you pick one, and Custom takes your own lengths in pixels, drawn and gap in turn, such as 12 4 0 4. A length of 0 is a dot, which only shows with round or square caps, so picking Dotted turns butt caps round. Caps finishes the ends of a line, an open path, and every dash: butt stops at the end, square reaches half the width past it, and round finishes it with a half circle. Joins turns the outside of each corner: miter carries the edges on to a point, round rounds it, and bevel cuts it off. A miter longer than the Miter limit, measured in half the stroke’s width, is beveled instead; 1 bevels every corner and 4 is the usual default. Dash lengths belong to the shape, so they grow and shrink with it when the Move tool scales it.

Arrowheads, stars, and corners

A line or an open path can end in an arrowhead. In the inspector’s Shape section, Start arrow and End arrow each pick a filled triangle, an open chevron (drawn with the stroke’s own caps and joins), a circle centred on the end, or a bar across it. W sets how wide it is across the stroke and L how far it reaches back along it, both in widths of the stroke, so an arrowhead grows when you make the stroke wider. An arrowhead replaces that end’s cap, points the way the line arrives, and is drawn whole however the dashes fall.

A star has a number of Points and an Inner radius: how far out its inner corners lie, as a share of the way to its points. At 100% it is a polygon of twice as many sides; lower values sharpen the points.

A rounded rectangle’s corners start linked, with one Corner radius for all four. Untick Link corners to give each its own, top left, top right, bottom right, and bottom left; ticking it again gives every corner the top left’s. Two corners on the same side share it in proportion to their radii, so a large corner beside a square one can use the whole side.

Drawing paths with the Pen

The Pen tool (P) draws your own shapes out of curves. Click to put down a corner; press and drag to put down a smooth point, whose handles follow the pointer and bend the curve through it. Hold Shift to put the next point at a multiple of 45 degrees from the last. Click the first point to close the path, or press Enter to finish it open; Backspace takes the last point back and Escape abandons the path. A finished path becomes a shape layer painted with the fill and stroke in the strip beside the tools, and an open one is always stroked. Set the strip’s first list to Selection and the path becomes the selection instead, added to, subtracted from, or intersected with the one you have by holding Shift, Alt, or both as you put down its first point.

The Direct Selection tool (A) shows the selected path layer’s points and handles. Drag a point to move it with its handles, or drag a handle to reshape the curve: a smooth point turns its other handle to match, and holding Alt moves one handle alone. Alt-click a point to make it a sharp corner. Each drag is one step to undo. The inspector’s Closed box opens or closes the path, and Select > From Shape selects inside it like any other shape.

Combining shapes

One shape layer can be made of several shapes. With a shape layer selected, draw another shape over it holding Shift to add it, Alt to cut it out, or both to keep only where the two overlap. The second list in the strip beside the tools does the same without the keys, and also offers Exclude, which keeps where exactly one of them covers and leaves the overlap a hole; with it set to New layer a shape is a layer of its own, as usual. The Pen tool uses the same list and keys for the path it draws. Layer > Combine Shapes merges the selected shape layers into one, keeping the fill and stroke of the lowest. Each step is one to undo.

The fill and stroke paint the outline the shapes make together, so a hole is outlined too and an edge inside the shape is not. The inspector lists the shapes it is made of, where you can change how each combines or remove it, and its Fill rule decides what happens where a path crosses itself or loops inside itself: Non-zero fills it and Even-odd leaves it a hole. Select > From Shape selects the combined outline, holes and all.

Selecting and masking

A selection decides which part of the picture a mask or an adjustment covers. Choose a selection tool from the tool strip over the canvas, where each tool’s name sits under its icon. When the chosen tool’s options need the room, the names give way to icons alone and show as tooltips instead:

  • Marquee (M, press again for the ellipse): drag a rectangle or ellipse.
  • Lasso (L, press again for the polygonal lasso): draw freehand or click corners.
  • Magic Wand (W): click a colour to select the pixels near it.
  • Quick Selection (W again from the wand): paint over part of a subject and the selection grows out to the edges near the stroke. Tolerance decides how far in colour from what you painted over it may spread, and Edge how sharp a change in colour stops it; [ and ] change the brush’s size. Each stroke adds to a quick selection already there, Alt takes one away, and Deselect starts again. Select > Refine Edge afterwards tidies hair and soft edges the stroke found.
  • Brush (B): paint into the selection; hold Alt or press X to erase, and [ and ] change its size.
  • Gradient (G): drag a ramp that fades the selection from where you press to where you let go, along the drag (Linear) or out from its start (Radial). Drag either handle afterwards to move that end; pressing Shift once the drag has started keeps it to 45 degree steps.

Hold Shift as you start to add to the selection, Alt to subtract, or both to intersect.

The Brush tool’s Tip button, beside its size and hardness, shapes how it paints:

  • Spacing: at Continuous the tip is swept along the stroke with no gaps, and doubling back never builds up. Above that it stamps separate dabs this far apart, as a share of the brush’s size.
  • Flow: how much each dab adds. Dabs build up where they overlap, so a low flow darkens gradually as you paint over the same place, like an airbrush. On a continuous stroke it is the stroke’s strength.
  • Scatter: how far each dab may stray across the stroke, as a share of the brush’s size. It needs a spacing.
  • Angle and Roundness: below 100% roundness the tip is an ellipse, turned by the angle, for a calligraphic edge. The outline under the pointer shows its shape.
  • Smoothing: the stroke trails the pointer by this many screen pixels on a string, which takes the wobble out of a hand-drawn line.

Preset lists saved brushes. Type a name and Save Preset to keep the current size, hardness, and tip settings under it (a name already listed is replaced), or Delete Preset to remove it. Presets are kept in the app’s settings, so every document can use them. The tip settings are written into each stroke, so it still paints the same dabs at any export size.

Symmetry painting

The Brush, the Clone Stamp, Spot Healing and Liquify can paint with symmetry. The Symmetry button at the end of each tool’s options (in the Liquify window, under Symmetry) picks how each stroke is repeated:

  • Vertical mirrors it across a vertical axis, left to right.
  • Horizontal mirrors it across a horizontal axis, top to bottom.
  • Both mirrors it across both, so it is painted four times.
  • Radial turns it about a centre, from 2 to 32 Segments.

The axes are drawn over the canvas, and the handle where they cross drags them anywhere on it. Hold Shift while dragging to snap the handle to the canvas’s centre, or choose Centre the Axes. The button is lit while symmetry is on, and the brush outline shows under the pointer and at every copy.

A stroke and its copies are one stroke and one undo step. The stroke records its symmetry in its own frame, so it is redrawn the same at any export size, and it follows its layer when the layer moves. A mirrored clone copies its source mirrored too, and a mirrored twirl turns the other way.

A gradient makes a graduated filter: drag one down over the sky, then Select > Limit Adjustment to Selection on an exposure, and the sky darkens and fades out towards the horizon.

The Select menu holds everything else: All (Ctrl+A), Deselect (Ctrl+D), Invert (Ctrl+Shift+I), Feather (Shift+F6), Modify to grow, shrink, border, or smooth, and Color Range to select by colour.

Select > Refine Edge works on the edge of the selection you have. Its View shows the selection under a red overlay, on black, or on white, and the canvas updates as you drag:

  • Radius looks this far either side of the edge and fits it to the selected layer’s own pixels, so a rough outline picks up hair, foliage, or a skyline beside it. Layers with no pixels of their own, such as text and groups, skip it.
  • Smooth rounds off corners and specks, Feather softens the edge, Contrast hardens it again, and Shift Edge moves it outwards (positive) or inwards (negative).
  • Decontaminate Colors only matters to a mask: it replaces the colour along the edge with the colour of the nearby fully selected pixels, so a background’s colour does not fringe what is kept. Amount sets how much. Exports of a document that uses it are not banded.

OK adds the refinement to the end of the selection’s recipe. Opening Refine Edge again edits it rather than adding a second one, and undo takes it back. Like Modify, it follows the selection into a mask and scales with the layer, so the export refines exactly what the preview showed.

Select > From Layer Transparency, or Ctrl+click on a layer’s thumbnail, selects what that layer draws; Shift adds it to the selection and Alt subtracts it. The selection names the layer rather than copying it, so a mask made from it follows the layer when it moves. Deleting, merging, or ungrouping the layer keeps the mask’s shape, warps and all, as the pixels the layer drew.

Save Selection keeps a selection in the project under a name, and Load Selection brings it back or combines it with the current one.

Masks and limited adjustments

Select > Add Mask hides the selected layer outside the selection. Limit Adjustment to Selection confines one adjustment to it. Both stay editable: load one back with its Edit button, change the selection, and write it back with Replace Mask with Selection.

Retouching

Two brushes copy one part of a layer over another, to take out dust, blemishes, and stray wires. Both paint on the selected layer and keep what they paint as a recipe: each stroke is added to a Retouch adjustment at the top of the layer’s stack, or to a new one put there, so the layer’s own pixels are never changed. Switch the adjustment off to see the layer without its retouching, use Remove Last Stroke in the inspector to take a stroke back off, or undo it. Strokes move, scale, and turn with the layer, and an export retouches exactly what the preview showed. A layer whose pixels are locked can’t be retouched.

  • Clone Stamp (S): Alt-click to set the source, then paint to copy it. With Aligned (the link button) on, the first stroke fixes the distance between the source and the brush and every later stroke keeps it, so the source moves with the brush; off, every stroke starts copying from the source again. A cross shows where the brush is copying from.
  • Spot Healing (J): paint over a blemish. When you let go, ImageGui looks around the stroke for the nearby patch whose surroundings best match the stroke’s, copies it, and shifts its brightness and colour so it meets the edge of the stroke, matching both the level and the gradient there.

Both have a size, set with [ and ] as well as the slider, and a hardness: a soft brush blends its edge into the picture. A stroke reads the layer as the adjustments beneath its Retouch leave it, and each stroke reads what the strokes before it painted.

Content-Aware Fill

For something too big to paint out, select it and choose Edit > Content-Aware Fill. ImageGui fills the selection on the selected image layer from the rest of the layer: it searches the picture for the patches that best continue what surrounds the hole, first on a small copy and then on finer ones, and copies them in, so texture carries on through the fill rather than being smeared across it. Where what it copies is lit a little differently from the edge of the selection, as sky beside a glow is, the copy’s level is bent to meet the edge, so no seam shows.

The dialog previews the fill before you commit to it. Each Seed searches the picture its own way, so if the fill copied something you don’t want, Try Another searches again. To keep it from copying a particular area, save a selection over that area first (Select > Save Selection) and pick it under Don’t copy from. The selection can be feathered or soft: the fill blends in where it is.

OK adds a Content-Aware Fill adjustment at the top of the layer’s stack, holding the selection and the seed, so the layer’s own pixels are never changed. Change the seed from the inspector later, switch the fill off, or undo it. An export fills the same way the preview does, at full size. A layer whose pixels are locked can’t be filled.

The fill looks at the whole layer, so on a very large picture it is one of the slower things on a layer’s stack, a second or so on a 24-megapixel photo with a large hole.

Liquify

Filter > Liquify turns the canvas into a brush that pushes the selected image layer’s pixels around, like soft clay. A window opens beside the canvas with five tools:

  • Forward Warp pushes the pixels the way the brush moves.
  • Twirl turns them about the brush’s centre while you hold or drag it.
  • Pucker draws them in towards the centre, and Bloat swells them out from it.
  • Reconstruct paints the pixels back towards where they started.

Each tool has a size (also [ and ]), a pressure, which is how strongly a dab moves the pixels, and a density, which is how much of the brush moves them fully before the effect fades to its edge. Holding the brush still keeps twirling, puckering, or bloating.

The strokes are a recipe, not pixels: they are added to a Liquify adjustment at the top of the layer’s stack, so you can switch it off, take the last stroke off from the inspector, or undo it. They follow the layer when it moves, and an export redraws them at full size. Restore All takes every stroke off at once, OK closes the window keeping them, and Cancel takes back everything painted since the window opened. A layer whose pixels are locked can’t be liquified.

Vector masks

A vector mask hides a layer outside an outline, and the outline stays sharp at every zoom and export size. Any layer, group, text, fill, or shape can carry one.

  • Draw one: turn on Mask in the Shape or Pen tool’s options, then draw. The shape or path becomes the selected layer’s mask instead of a new layer. With a mask already there, Shift, Alt, or the combine mode add to it, cut from it, or intersect with it, just as they do with a shape layer.
  • Take one from a shape layer: Layer > Vector Mask > From Shape Layer uses that layer’s outline where it lies now. The shape layer itself is left as it is.
  • Edit it: the inspector’s Vector mask section, and the same menu, turn it on and off, invert it, and feather its edge. Convert to Mask turns it into an ordinary mask you can paint on and refine.

The mask works together with the layer’s other masks: only what all of them show stays visible. It moves, scales, and turns with its layer. The Layers panel shows it beside the layer’s thumbnail. A pixel lock stops any change to the mask, and a position lock stops drawing a new one. A layer in perspective can’t take one.

Geometry: crop, straighten, turn, and resize

These all change where a layer sits rather than its pixels, so they can be undone or changed at any time without losing quality.

Crop in the inspector draws a crop box: drag its corners and edges, lock an aspect ratio if you like, then Apply crop.

The guide drawn over the crop box is picked from its Overlay list, or cycled with O: thirds, the golden ratio, a golden spiral, diagonals, triangles, and a fine grid. Shift+O flips the spiral and the triangles round, and the choice is remembered for the next crop.

Straighten turns the selected layer by an angle. Draw horizon lets you draw a line along something that should be level, and turns the picture to match.

Auto, beside the Straighten field, finds the strongest near-level or upright line in the picture and levels it in one undo step, which the field can then fine-tune. A picture with no clear line is left alone, and the panel says so.

Measuring

The Measure tool (I) drags a line across the canvas. A label beside the line and the Info panel read out its length, its angle (counterclockwise from pointing right, so a line rising to the right is positive), and how far it runs across (dx) and down (dy). Lengths are in the document’s pixels, or in inches, centimetres, or millimetres at the resolution (ppi) you enter beside the unit, since a picture carries no resolution of its own.

  • Drag either end to move it; click anywhere else, or press Esc, to clear the line.
  • The ends catch on the canvas edges and centre lines, guides, and layer edges while View > Snap is on. Hold Ctrl to place them freely, and Shift to hold the line to 45° steps.
  • Straighten to this line turns the selected layer so the line is level, or upright when it is nearer upright, as one undoable step. The Straighten field carries on from the result.

The line is only for looking: nothing about it is saved, and it goes when the canvas changes size.

Image > Perspective Crop puts four corners on the picture. Drag each onto a corner of something photographed at an angle, such as a page or a building’s face, and applying makes that shape the whole canvas, straightened.

The Image menu rotates by quarter and half turns, flips horizontally or vertically, and changes the picture’s size:

  • Image Size resamples the whole picture to a new size.
  • Canvas Size adds or removes canvas around the picture without scaling it, and Trim crops to everything visible.
  • Resampling chooses the filter used for the preview and the export alike. Lanczos-3 is the default; nearest keeps hard pixel edges for pixel art.

Saving and exporting

File > Save (Ctrl+S) writes an .imagegui project that keeps your layers, adjustments, and edits, and links to your original images. Save As (Ctrl+Shift+S) saves under a new name, and Save Packaged Copy writes a project that carries its originals inside it, for moving to another machine. A project remembers its selection and straighten angle, so you pick up where you left off.

Saved versions

Each time you save over a project, the save it replaces is kept in a folder beside it, named after the project with .versions on the end (Photo.imagegui.versions). File > Preferences > Keep earlier saves sets how many: five unless you change it, and the oldest past that are deleted when you save. None stops keeping new ones without deleting those already kept.

File > Versions lists the earlier saves of the open project, newest first, each with its thumbnail and the time it was saved. Open as Copy opens one as a new, untitled picture and leaves the project alone; saving it asks where. Restore replaces the open picture with that version as one step, so Ctrl+Z brings back what you had, and the next Save writes it over the project. Versions are earlier saves only: work you haven’t saved is protected by autosave and crash recovery instead.

File > Export writes the finished picture as PNG, JPEG, WebP, TIFF, PDF, or SVG. It asks what size to write at (the picture’s own size, a percentage, or a long edge in pixels) and, for JPEG and WebP, a quality. Both are remembered for next time.

Beneath the options is a preview of the file: the picture as that format and quality will write it, at 1:1 in a window you can drag around, and how big the file will be. Both catch up a moment after you stop moving a control. Compare with original flips the window to the picture before encoding, which is the quickest way to find the lowest quality that still looks right. An export of up to two megapixels is encoded whole, so its size is exact; a larger one is previewed and measured from a smaller copy, and the size is marked as an estimate.

TIFF is written losslessly, LZW-compressed, so it asks only for a size. A PDF is one page titled after its file: either the picture’s size at a chosen number of pixels an inch, or A4, A3, A5, Letter, Legal, or Tabloid turned to match the picture, which it fits inside or fills. The picture is stored in it as JPEG at the chosen quality, or losslessly.

Dithered gradients

Every export except SVG’s vectors is written at 8 bits a channel, 256 levels, and a smooth gradient that crosses only a few of them would show each as a flat band. So where the picture becomes 8 bits, in exports, on the canvas, and when copying to the clipboard, each pixel between two levels takes the upper one as often as it lies towards it, in a fixed pattern finer than a level. Gradient fills, glows, vignettes, and soft skies come out smooth, and a patch averages to the light it was meant to have. A colour that already sits exactly on a level, such as an untouched photo’s, is written exactly as it was, so dithering never adds noise to a picture that had nothing to lose.

The pattern depends only on where a pixel is, so the same document exports to the same bytes every time, however it is split up to save memory. File > Preferences > Appearance > Dither gradients on 8-bit output turns it off; it is on unless you do. It applies to what leaves ImageGui: exports, batch runs, export sets and the export preview. Pictures ImageGui keeps inside a project, such as a merged, flattened or pasted layer, a new pattern, or the project’s thumbnail, are never dithered, so the setting can’t change what a project holds. Copying to the clipboard isn’t dithered either, so pasting back what you copied gives the same pixels whatever the setting.

Saving is just as repeatable. Saving an unchanged project writes the same bytes as last time, on any computer, and so does exporting the same PDF again: neither records when it was written.

Exporting as SVG

Name the export .svg to write a vector file. Shape and text layers become real paths: text is converted to outlines, so the file needs none of its fonts, and keeps its coloured runs, underlines, and strikethroughs. Fills, strokes with their dashes, caps, joins, and miter limit, opacity, blend modes, and groups become SVG attributes, and solid fill layers become rectangles. Everything else is embedded as a PNG of that layer at the export’s size, cropped to what it covers: photos, gradient and pattern fills, and any layer with adjustments, masks, effects, or a perspective. So is a layer with others clipped to it, drawn together with them. A layer in a blend mode SVG doesn’t have, such as Linear Burn, depends on what is beneath it, so it is drawn as one picture with everything below it.

The export options list each layer that will be drawn as a picture and why, before anything is written. The size you choose is the size the SVG is shown at; its coordinates stay in canvas pixels. SVG viewers blend translucent layers in sRGB where ImageGui blends in linear light, so translucent edges and blend modes can look slightly different from the canvas.

File > Export Layers writes each top-level layer, or each selected one, to a file of its own. A document with layer comps can instead write each comp as the whole picture.

Exporting an animation

File > Export Animation writes an animated GIF or WebP whose frames are your layer comps, in the order the panel lists them, or each layer at the top of the stack shown on its own, from the bottom up. Layers are used whether their eye is on or not, so a document can keep every frame but one hidden. Choose a file, then:

  • Format: GIF plays everywhere. Each frame gets a palette of its own of up to 256 colours, and a pixel is either clear or solid. WebP keeps every colour and soft edges, at the quality you choose, but holds every frame in memory until the file is written.
  • Size: the same choices as Export: the picture’s own size, a percentage, or a long edge.
  • Loop forever, or turn it off and say how many times the animation plays.
  • Timing: the field above the frame list sets every frame at once, and each frame’s own field changes just that one. GIF keeps time in hundredths of a second, so its delays round to the nearest 10 ms.

Frames are rendered as Export renders the picture. Stop in the progress window abandons the export and writes nothing. Batch can’t write animations, since it works on image files, which have neither comps nor layers.

Exporting several files at once

File > Export As Set asks for a folder, then writes every output of a set there in one go. Each output has its own format, quality, size, and a suffix that goes between the picture’s name and the extension, so the set that comes with ImageGui writes photo-web.jpg at 2048 pixels on the long edge, photo-print.tif at full size, and photo-thumb.webp at 512. Make new sets, duplicate, rename, and edit them in the same window; Save Sets keeps your changes without exporting. Outputs of the same size share one rendering of the picture, and the window says how many renderings the set needs. In File > Batch, choose an export set to write the whole set for every picture.

Batches and the command line

File > Batch runs a set of pictures, or every picture directly inside a folder, through one of your adjustment presets and writes each one to an output folder as PNG, JPEG, WebP, TIFF, PDF, or SVG, or as a whole export set. A saved project can be part of a batch too: it is written as it was saved, without the preset, and with Each artboard of a project ticked a project with artboards is written one picture per artboard. The same batch runs without a window from the command line:

ImageGui --batch --out web --preset "Golden hour" --size 2048 --format jpg --quality 85 photos/
ImageGui --batch --out delivery --set "Web, print and thumbnail" photos/

--format is one of png, jpg, webp, tif, pdf, or svg; without it each picture keeps its own format. --size is the long edge in pixels and --percent a percentage; neither enlarges. --set names an export set saved in the app (the name’s case doesn’t matter) and writes every output of it for each picture. A set chooses its own formats, qualities, and sizes, so it can’t be combined with --format, --quality, --size, or --percent. --artboards each writes each artboard of a project as a picture of its own; --artboards whole, the default, writes its whole canvas. The command exits with 0 when every picture was written, 1 when any failed, and 2 when the command line couldn’t be understood or names a preset or set that isn’t saved.

Comparing pictures

File > Compare Images shows two pictures, or two projects as they render, against each other. It opens with the current file on the after side; choose the before side, or press Last Commit to compare the file with the version git last committed. That reads the committed file through the repository’s filters, so pictures kept in Git LFS work too.

The pictures pan and zoom together, and the keys 1 to 4 switch between the four ways of showing them:

  • Side by Side puts them next to each other.
  • Swipe lays one over the other with a divider to drag across.
  • Onion Skin fades the after picture over the before, at the opacity you choose.
  • Difference shows where they differ.

A change of a level or two can’t be seen by eye, so Difference is built to find it. Highlight dims the picture to grey and paints every changed pixel magenta, and Exaggerate multiplies each difference, up to 255 times, until the faintest one is at full strength. Absolute shows the difference itself on black instead. Ignore up to treats differences of that many levels or fewer as none, which hides the noise a JPEG re-save leaves. The line under the picture counts the changed pixels, gives the largest difference, and says where the changes lie. Pictures of different sizes are lined up at their top-left corners, and the extra area counts as changed.

Git history

A picture or project opened from a git repository gets a Git History panel listing every commit that changed it, newest first, with a thumbnail of each version, who made it and when. It follows the file back through renames, and when the file on disk differs from its last commit a Working copy row heads the list. Saving or committing updates it by itself; Refresh reads it again on demand.

Choose a commit and press Compare with Previous, or double-click it, to see what that commit changed in Compare Images. Compare with Working Copy sets the chosen version against the file on disk. Every version is read through the repository’s filters, so pictures in Git LFS work. A file git doesn’t know shows no panel, and View > Git History turns the panel off and back on.

Using ImageGui as git’s diff tool for pictures

ImageGui --diff old.png new.png opens a window showing just the comparison, which closes with Escape. That makes it a difftool for git. With ImageGui on your PATH, set it up once:

git config --global difftool.imagegui.cmd 'ImageGui --diff "$LOCAL" "$REMOTE" --name "$MERGED"'

Then git difftool -t imagegui -- art/logo.png compares the working copy of the picture with the last commit, and git difftool -t imagegui main -- art/ steps through every changed picture under art/ one window at a time. Add git config --global diff.tool imagegui to make it the default for git difftool.

To have plain git diff open pictures in ImageGui, register it as a diff driver and mark which files use it in the repository’s .gitattributes:

git config --global diff.imagegui.command "ImageGui --diff"
*.png diff=imagegui
*.jpg diff=imagegui
*.imagegui diff=imagegui

git passes its usual seven arguments to the driver and ImageGui reads the two files and the path from them. An added or deleted picture is shown against nothing. git log -p uses the driver too when given --ext-diff.

Given --out, the comparison runs without a window and writes the Difference view to a file, for scripts and checks:

ImageGui --diff before.png after.png --out difference.png --exaggerate 16 --tolerance 2

--style is highlight (the default) or absolute, --exaggerate runs from 1 to 255, and --tolerance is the Ignore up to level, from 0 to 254. It prints the same summary the window shows and exits with 0 when the pictures match within the tolerance, 1 when they differ, and 2 when a picture couldn’t be read or the command line couldn’t be understood.

Undo and history

Edit > Undo (Ctrl+Z) and Redo (Ctrl+Y) step through every change, including each drag. View > History lists the steps by name, marks the one the saved file holds, and jumps to any step in one click.

Undo keeps the pixels of layers you delete, merge, rasterize, or relink, so they can come back. The line at the top of History says how much memory that takes. File > Preferences > History memory limit (1 GB unless you change it) caps it: past the limit, the oldest steps are let go, and the first row becomes the oldest state kept rather than the picture as it was opened. The newest step is always kept, however large. If the step a save wrote is let go, the project reads as unsaved until you save again.

New Snapshot, at the top of History, keeps the picture as it is now under a name (type one in the field beside it, or leave it empty for Snapshot 1, Snapshot 2, …). Snapshots are listed above the steps. Click one to return to it: that’s one new step, so Ctrl+Z takes you back to where you were, and everything you did after the snapshot stays in the history. Right-click a snapshot to delete it. Snapshots last until you open another picture and aren’t saved with the project. They count toward the history memory limit, but they’re the last thing let go: the oldest steps go first. If a snapshot does have to go, a message names it.

Preferences

File > Preferences holds settings that belong to you rather than to a document: how large the interface is drawn and in which colours, how often unsaved work is autosaved, how much memory undo may hold, how many earlier saves of a project are kept, whether a launch reopens what was open, how layer thumbnails are framed, whether Rasterize, Merge Down, and Flatten Image ask first, the clipping overlay’s thresholds, and whether double-clicking an .imagegui project in your file manager opens it in ImageGui.

The Appearance tab holds the interface size, the theme, and whether gradients are dithered where they become 8 bits (see Dithered gradients).

Interface size runs from 75% to 200% of the size your display’s DPI gives, which is 100%. It applies at once and is remembered; the Accessibility menu’s UI Scale sets the same thing. Menus, panels, the canvas’s handles, and the distance a click can wander before it becomes a drag all grow together, and the canvas’s zoom is left alone.

Theme is Dark (the default), Light, or Follow the system, which uses whichever your operating system is set to and changes with it while ImageGui runs. On Linux the system’s setting is read from GNOME’s color-scheme, or the GTK theme’s name. The space around the picture, the rulers, and the guides change with the theme; marks drawn over the picture itself, such as selection outlines and handles, keep their black and white so they show on any image. Both themes keep text and hints at a contrast of at least 4.5:1 against the panels, and disabled text, graphs, and the keyboard-focus outline at least 3:1. Graphs draw their red, green, and blue darker in the light theme so they show on its white frame.

The Performance tab holds the Preview cache: how much of the evaluated picture ImageGui keeps so that a drag redraws only the layer and adjustments it changes. Automatic, the default, takes an eighth of your computer’s memory, never less than 512 MB nor more than 4 GB; a busy 24 MP picture needs about 700 MB at the 2048 px preview size. The line beneath says how much is held now. A smaller cache is applied at once, letting go of the least recently used results first.

The Keyboard tab rebinds every menu shortcut and tool key: click a shortcut and press the new keys. The menus show whatever is bound, a chord two commands share is flagged on both rows, and Reset or Reset All puts the defaults back.

Keyboard shortcuts

These are the default shortcuts. Shortcuts that act on layers or the canvas are ignored while you are typing in a text field.

Help > Keyboard Shortcuts (Ctrl+/) opens a window listing every command with the shortcut it has now, including any you have changed, grouped like the menus. Type in its search box to find a command by name, by menu, or by its keys, such as ctrl+j. Each row’s Change… button opens Preferences on the Keyboard tab, already listening for the new keys.

Help > Command Palette (Ctrl+Shift+P) finds any command by typing part of its name, such as merge or drop sh, and runs the highlighted one when you press Enter; the arrow keys move the highlight and a click runs a row too. It lists every item of every menu, so adjustments (under Layer > New Adjustment), layer effects (switched on and off under Layer > Layer Effects), and panels (the View menu) are all found the same way, along with the tools. Each row shows its shortcut, and a command that can’t run right now stays in the list, greyed, with the reason underneath.
