An image editor
for engineers.

ImageGui holds every adjustment as a live entry in a layer tree, so nothing gets burned into pixels and any edit stays open for revision. It works in linear light from decode to encode, and runs one evaluator for both the preview and the full-resolution export. Installed as a dotnet tool.

How It Works

Five Decisions the Rest Follows From

Linear Light from End to End

Pixels decode to linear floating-point RGBA the moment a file opens, and stay that way until one gets written. sRGB conversion happens at the two places it belongs, the codec and the screen. Adjustments compose without banding, and values stay intact above 1.0 until the export clamps them.

A Layer Tree

A group is a node whose pixels come from its children, which makes it ordinary rather than a special case in the evaluator. One mask covers everything inside a group, and groups carry their own blend mode and opacity for free.

One Evaluator for Preview and Export

The on-screen preview and the full-resolution export run the same code at different scales. What appears on screen matches what gets written because a single implementation produces both, rather than two kept carefully in step.

Incremental Re-evaluation

Every node caches its result against the inputs that actually affect it. Editing a layer invalidates that layer and the groups above it, leaving its siblings and neighboring branches intact. Re-evaluation runs off the UI thread and cancels as soon as the slider moves again.

A Headless Core

ktsu.ImageGui.Core has no UI dependency of any kind. The pixel buffer, the document model, the evaluator and the codecs are a plain .NET library, with the filesystem, hashing and caching injected through interfaces. The imaging behavior is testable without a window on screen, which is the property that keeps the color math honest.

Scope

Scope and Boundaries

The first list is built and the second is a boundary. Retouching and painting belong to a different craft, so they stay out of scope regardless of schedule.

In Scope

Geometry
Crop, resize, rotate, straighten, flip, perspective crop, skew and distort. Held as placements that stay open for revision.
Tone and Color
Levels, curves, exposure, white balance, HSL, color balance, channel mixer, gradient map, sharpen, blur, dehaze, noise reduction and lens correction, each with its own opacity and blend mode.
Layers and Compositing
Groups, twenty-six blend modes, opacity, masks, clipping, fill and pattern layers, layer effects and layer comps.
Text and Shapes
Text drawn from font outlines with styled runs, and vector shapes and Pen paths, all sharp at any scale.
Selections
Marquee, lasso, brush, magic wand, color range, gradient and layer transparency, as a way to build masks.
Output
PNG, JPEG, WebP, TIFF and PDF with a live export preview, and batch processing from the menu or the command line.

Out of Scope

Brush and Paint Tools
The brush paints selections, never pixels. Painting onto an image works against keeping every edit open for revision.
Clone, Heal, Spot Removal
Retouching is a different craft with a different set of tools behind it.
Camera RAW
Deferred rather than refused. The pipeline covers screenshots, web images, scans and camera JPEGs first.
Roadmap

Six Milestones, in Dependency Order

  1. M1

    The Vertical SliceBuilt

    Open PNG, JPEG and WebP. Exposure on a live slider. Pan and zoom. Export at full resolution. Undo and redo. Packaged as a dotnet tool.

  2. M2

    AdjustmentsBuilt

    Levels, curves, brightness and contrast, saturation and vibrance, white balance, per-channel HSL, black and white. This is the milestone that makes it useful day to day.

  3. M3

    GeometryBuilt

    Crop with aspect presets, resize with a choice of resampling filter, rotate, straighten against a drawn horizon, flip. The first operations where proxy and full resolution have to be proven to agree.

  4. M4

    Project FilesBuilt

    A versioned document format, so non-destructive work survives closing the app. Window state, recent files and preview size come with it.

  5. M5

    Layers on ScreenBuilt

    Add an image as a layer. Group, ungroup, drag to reorder and re-parent. Visibility, blend mode, opacity. Text and watermark layers.

  6. M6

    Selections and MasksBuilt

    Rectangular and elliptical marquee, lasso, color-range selection, feathering. Each one binds to a layer mask or to the coverage channel of a single adjustment for a local edit.

Since Milestone 6

Text styled a run at a time and edited on the canvas, shape layers, the Pen tool and shape booleans, layer effects under one global light, pattern fills, perspective placements, the magic wand and gradient selections, lens correction, TIFF and PDF, an export preview, batch processing, and a preview cache and undo history sized from memory. Next is text on a path and warped text.
