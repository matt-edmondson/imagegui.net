Image Editor · Windows, macOS, and Linux

Every edit
stays open.

ImageGui is a layer-based image editor that never changes the pictures it opens. Adjustments, crops, masks, text, retouching, and warps are all kept as steps on top of the originals, so any of them can be edited, reordered, or switched off a week later. It works in linear light from the moment a file opens until one is written, and the preview and the export come out of the same code.

Intro

Kept Edits, Repeatable Output, and a Record of Changes

ImageGui is for people who care how a picture was made as much as how it looks. That means an edit that can still be changed a month later, an export that matches what was approved, and a clear record of what changed between two versions. It covers the photo side and the layout side of the job in one app.

Non-Destructive Workflows

The pictures a project opens are never written to. An adjustment, a crop, a mask, a brush stroke, a clone, or a Liquify push is a step stored over the original, so any of it can be changed, turned off, or removed long after it was made. A project links to its originals and stays small, and a packaged copy carries them along when it has to move.

Determinism

The canvas and the exported file are drawn by the same evaluator at different sizes, so the export matches the preview because nothing else could produce it. The 8-bit dither pattern depends only on where a pixel is, so a document exports to the same bytes every time, however export splits the work to save memory.

Versioning

Saving over a project keeps the earlier saves beside it, and File > Versions restores any of them as one undo step. In a git repository, the Git History panel lists every commit that changed a picture, and Compare Images shows what changed down to a single level. ImageGui also works as git’s diff tool for pictures, sets a repository up for itself, and commits a project along with every picture it depends on.

Linear Light

Pixels decode to linear floating point as a file opens and stay that way until one is written. Exposure, blending, blur, and resampling all happen on light rather than on the encoded values a file stores, and the 8-bit output is dithered so gradients leave without bands. Who It’s For

Photographers Editing Their Own Pictures

Tone and color are adjusted in linear light on a stack that stays editable, with Levels and Curves drawn over the histogram they change. Spot Healing, the Clone Stamp, and Content-Aware Fill clean a picture up, and a large photo opens on a draft first, so a drag only redraws what it changes.

Designers Building Layouts

Text is shaped with HarfBuzz and edited on the canvas, shapes and paths stay vectors, and artboards hold several sizes of one design in a single project. Layer effects, layer comps, and export sets turn one file into the set of pictures a launch or a social post needs.

People Moving Off Photoshop

PSD and PSB files open with their layers, and the tools carry the names people already know, from Quick Selection and Refine Edge to Liquify. The same app runs on Windows, macOS, and Linux, so a project doesn’t have to change machines to change hands.

Anyone With Repeat Work

Saved presets, export sets, and batch export from the app or the command line handle the jobs that come back every week. Autosave, crash recovery, and the History panel keep a long session safe while it runs.

Opening and Starting Out

ImageGui opens PNG, JPEG, WebP, and TIFF pictures, Photoshop files with their layers, and its own .imagegui projects. A project links to the original pictures rather than copying them, so it stays small, and a packaged copy carries them along when the project has to travel.

Looking at the Picture

The canvas zooms to 3200%, turns like a sheet of paper on a desk, and carries rulers, guides, and notes. The readouts measure the finished picture, and none of the viewing aids touch what gets exported.

Tone and Color

Each layer holds a stack of twenty-four adjustments that can be reordered, switched off, faded, blended, or limited to a selection at any point. Levels and curves draw the histogram of the pixels reaching them, not of the finished picture, because that’s the distribution they act on.

Layers

A document is a tree of image, text, fill, shape, and placed-project layers in groups. Every layer change is one undo step, an opacity drag included, and blending happens in linear light, so the gray that leaves Overlay unchanged is half the light rather than an sRGB 50% swatch.

Fills and Layer Effects

Fill layers and effects have no pixels of their own. They’re drawn at whatever size the canvas is shown or exported, so they stay crisp, and an effect follows its layer’s shape through text edits, scaling, and clipping.

Text

Text is shaped with HarfBuzz and drawn from the font’s outlines, so kerning and ligatures come out as the font intends and the text stays sharp at any scale. It’s edited right on the canvas and stays editable for the life of the project, through warps, paths, and perspective.

Shapes and Paths

Shapes are vector layers with a fill and a stroke, drawn at whatever scale the canvas is. They take adjustments, masks, effects, and locks like any other layer, and combine into one outline.

Selections and Masks

A selection is a recipe of steps rather than a channel of pixels. A marquee, a wand click, a brush stroke, or a refined edge each become a step, so a mask follows its layer when it moves, costs a few hundred bytes to save, and selects the same edge in the export as in the preview.

Retouching and Reshaping

Clone Stamp, Spot Healing, Content-Aware Fill, and Liquify keep their strokes as adjustments on the layer rather than painting into it. They follow the layer when it moves, can be switched off later, and are redrawn at full size on export.

Geometry

Crops, turns, and resizes change where a layer sits on the canvas rather than the pixels it’s made of. Every one of them composes into a single transform per layer, so a chain of them is sampled once, through the document’s chosen filter, and four quarter turns give back exactly the picture that went in.

Export

Export writes PNG, JPEG, WebP, TIFF, PDF, and SVG at a chosen size and quality, from the same code that draws the preview. A smaller export is evaluated at its own size rather than shrunk from a full-size one, and batches run from the app or the command line.

History and Recovery

Every change can be undone, an unsaved picture survives a crash, and each save keeps the one before it. Any two versions of a picture can be compared down to a single level, including versions kept in git. A crash report holds no pixels or folder names and is never sent anywhere.

Working With Git

A project and its pictures can live in a git repository like any other source file. ImageGui sets the repository up to show its own changes, commits a project along with everything it depends on, and lists what changed between two versions down to a moved curve point.

Commands and Preferences

Every command is reachable by name, every shortcut can be rebound, panels dock wherever they’re wanted, and the interface scales and switches theme without a restart.
