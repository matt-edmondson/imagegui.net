Image Editor · Windows, macOS, and Linux

Every edit
stays open.

ImageGui is a layer-based image editor that never changes the images it opens. Adjustments, crops, masks, text, retouching, and warps are all kept as steps on top of the originals, so any of them can be edited, reordered, or switched off a week later. It works in linear light from the moment a file opens until one is written, and the preview and the export come out of the same code.

Intro

Kept Edits, Repeatable Output, and a Record of Changes

ImageGui is for people who care how an image was made as much as how it looks. That means an edit that can still be changed a month later, an export that matches what was approved, and a clear record of what changed between two versions. It covers the photo, layout, and game art sides of the job in one app.

Non-Destructive Workflows

The images a project opens are never written to. An adjustment, a crop, a mask, a brush stroke, a clone, or a Liquify push is a step stored over the original, so any of it can be changed, turned off, or removed long after it was made. A project links to its originals and stays small, and a packaged copy carries them along when it has to move.

Determinism

The canvas and the exported file are drawn by the same evaluator at different sizes, so the export matches the preview because nothing else could produce it. The 8-bit dither pattern depends only on where a pixel is, so a document exports to the same bytes every time, however export splits the work to save memory.

Versioning

Saving over a project keeps the earlier saves beside it. One Versions panel lists those saves, snapshots, and every git commit that changed the image, says what each one changed, and restores any of them, or a single layer from one, as one undo step. In a git repository, ImageGui sets the repository up for itself, commits a project along with every image it depends on, merges two branches of a project layer by layer, and checks that exports still match their project.

Linear Light

Pixels decode to linear floating point as a file opens and stay that way until one is written. Exposure, blending, blur, and resampling all happen on light rather than on the encoded values a file stores, and the 8-bit output is dithered so gradients leave without bands. An image can also work in ACEScg, where light brighter than white keeps its value and is shown through the ACES 2.0 output transform. The slider below shows the difference on a test chart.

Who It’s For

Photographers Editing Their Own Images

Tone and color are adjusted in linear light on a stack that stays editable, with Levels and Curves drawn over the histogram they change. Camera raw files from most makers stay raw and develop again whenever their settings change. Spot Removal, the Clone tool, and Content-Aware Fill clean an image up, and a large photo opens on a draft first, so a drag only redraws what it changes.

Designers Building Layouts

Text is shaped with HarfBuzz and edited on the canvas, shapes and paths stay vectors, and artboards hold several sizes of one design in a single project. The Accessibility panel checks text contrast and color vision as the layout comes together. Layer effects, layer comps, and export sets turn one file into the set of images a launch or a social post needs.

People Moving Off Photoshop

PSD and PSB files open with their layers and export with them too, and the features carry the names people already know, from Quick Selection and Refine Edge to Liquify and Blend If. Tools are named for what they do, and the command palette still finds each one by the name other editors give it. The same app runs on Windows, macOS, and Linux, so a project doesn’t have to change machines to change hands.

Game and 3D Artists

Pixel art is drawn in whole pixels against a palette and animated with onion skin. Sprite sheets, trim sheets, 9-slice frames, normal maps, and texture graph materials export in the forms Unity, Godot, Unreal, and Blender read, and ImageGui works in ACEScg with OpenEXR when a render needs its full range. Add-ons for Blender and Godot open a texture here and reload it on every save.

Anyone With Repeat Work

Saved presets, export sets, and batches from the app, the command line, or a node graph handle the jobs that come back every week. Autosave, crash recovery, and the History panel keep a long session safe while it runs.
