ImageGui 1.0 Release Notes

ImageGui is a non-destructive image editor for Windows and Linux. Every change you make, from a curve to a crop to a raw photo’s white balance, stays editable for the life of the project. A project is a recipe, not a pile of pixels: it links to your originals, it diffs and merges cleanly in git, and every export remembers the project it came from, so you can always go back and change the recipe instead of painting over its result.

This is the first full release. Projects saved by it use format version 14, which every later release will open, and a project means one image: it exports to the same bytes on every machine.

Non-Destructive From Start to Finish

Adjustments. More than thirty adjustments stack on each layer, among them levels and curves drawn over a histogram of the pixels that actually reach them, color grading, Match Color, Shadows/Highlights, lens correction, Remove Halo, Channel Swap, Normal Map, Debayer, and Graph Filter. Each one has its own opacity, blend mode, and selection limit, and any stack can be saved as a preset.

Layers. Groups and pass-through groups, twenty-seven blend modes blended in linear light, Blend If, clipping, locks, links, color labels, search, layer comps, and artboards. Image, raw photo, paint, text, fill, shape, graph filter, and placed-project layers, with drop shadows, strokes, glows, overlays, bevel and emboss, and satin as layer effects.

Geometry. Crop with composition overlays, straighten by hand, along a line, or automatically, perspective crop, flips and turns, Image Size, Canvas Size, and Trim, all without touching the original pixels.

Texture graphs. Node graphs that draw procedural fills, masks, selections, and whole materials, and Graph Filters that read the layers beneath them, or any other layer, as images.

One Project, One Image

The same everywhere. A project opened in the same version of ImageGui exports to the same bytes on Windows and Linux, on any processor, however many cores render it. Saving an unchanged project writes the same file, and running the same batch over the same files writes the same outputs. Text depends on the fonts a machine has, so set it in a font both machines share, or embed the font in the project.

Exports you can prove. ImageGui --verify, and Verify exports in the Versions panel, find the version of the project an export was made from, write it again with the settings the export recorded, and compare the two files byte for byte. When they differ, ImageGui says how many pixels differ and by how much, names the layers responsible, and says whether another ImageGui version or a changed original would explain it.

Projects that keep opening. The project format is frozen at version 14 for 1.0. ImageGui is tested against projects saved by every earlier version, from 1 to 14, so each one opens, upgrades, and saves the same way every time.

Color You Can Trust

ACES. An image works in linear sRGB or in ACEScg, the working space film, visual effects, and game studios share. In ACEScg a highlight keeps its value however far above white it is, and the canvas, thumbnails, histogram, accessibility checks, and exports all go through the same ACES 2.0 output transform, for an sRGB, Display P3, or Rec.709 screen. Image > Color Management converts every color a project stores in one undo step.

OpenEXR. Open EXR files with their full range, and export them in half or full float as ACES2065-1, ACEScg, or Linear Rec.709, tagged so the next app reads them as they were meant.

Raw photos. Open DNG, Canon CR2 and CR3, Nikon NEF, Sony ARW, Fujifilm RAF, Olympus ORF, Panasonic RW2, and Pentax PEF files. A raw photo stays raw: the layer keeps the camera’s data, and white balance, highlight reconstruction, and detail develop it again whenever you change them, each change a step in the history.

Versions and Git

One Versions panel holds saves, snapshots, and git commits, with a summary of what each one changed, comparisons between images, and a way to bring back a single layer from any version. In a git repository ImageGui commits a project with the files it links to, works as git’s diff tool for images, merges projects layer by layer, resolves conflicts in a panel of its own, checks that exports are up to date, and verifies that an export is exactly what its project made. From any export you can open the project behind it, and with Update exports when this project is saved turned on, saving a project writes its exports again.

For Game Developers

The Pixel tool, document palettes, indexed PNG export, and whole-pixel scaling for pixel art. Channel packing with Unreal, HDRP, glTF, and Godot presets, normal map tools with a Normal Detail blend mode, TGA export, sprite sheets and atlases, trim sheets, 9-slice margins, onion skin for animation, and export targets that write into a Unity, Godot, or Unreal project every time you save.

Godot. A plugin for Godot 4.3 and later opens textures in ImageGui, reimports them on every save, and imports ImageGui projects directly. Exports into a Godot project come with their import settings, materials (including a packed ORM texture), SpriteFrames, TileSets, and style boxes.

Blender. An add-on for Blender 4.2 and later edits a texture in ImageGui and picks up each save. Multilayer renders open with their passes as layers, Cryptomatte drives selections, placed renders follow re-renders, and texture graphs export as PBR materials.

Help > Add-Ons for Other Apps shows where both are.

Batches and the Command Line

File > Batch runs images through a preset or a whole export set, from the app or from the command line. Batch graphs go further: draw a batch as a graph of steps such as Apply Preset, Resize, Crop to Aspect, Watermark, Convert Color, Export, and Save Project, preview it on up to eight sample images before anything is written, and write several kinds of output from one run. File > Batch runs a graph as well as a preset, and Edit as graph turns a batch you already run into a graph to build on.

Three starters come with ImageGui: Web and Print writes a web JPEG and a full-size TIFF of each image, Social Crops writes square, 4:5, and 16:9 crops sized for social posts, and Watermarked Proofs writes a smaller, watermarked JPEG proof. Open one from File > Batch Graphs > New from Starter to change it, or run it as it is.

A graph is saved as a small .imagegui-batch file that holds the presets and export sets it uses, so it runs the same on another computer, and ImageGui --batch --graph runs one, or a starter by name, without a window.

Everything Else

Opening. PNG, JPEG, WebP, TIFF, OpenEXR, GIF, BMP, and ICO images, camera raw photos, Photoshop files with their layers, and animations frame by frame as layers. A damaged file is refused with a message saying so. Paste from the clipboard, drop files onto the window, or start from a blank canvas. Help > Open Sample Project and a first-run tour show the main features at once.

Text. Shaped with HarfBuzz and drawn from outlines, so it stays sharp at any size. Styled runs, paragraphs, OpenType features, variable font axes, vertical text, named styles, warps, text on a path and inside a shape, font fallback, find and replace, and spell checking, all edited right on the canvas.

Shapes, painting, and retouching. Rectangles, ellipses, polygons, stars, lines with arrowheads, and Pen paths, combined with union, subtract, intersect, and exclude, plus a library of custom shapes. Brushes and brush tips kept as recipes, symmetry painting, the Clone Stamp, Spot Healing, Content-Aware Fill, Liquify, Displace, mesh warps, skew, and perspective distort.

Selecting and arranging. Marquees, lassos, the magic wand, Quick Selection, color range, and more, refined with Modify and Refine Edge and saved with the project. Align and distribute, smart guides, rulers, color samplers, measuring, notes on the canvas, and a second view of the same document.

Accessibility. An Accessibility panel and canvas overlay check text contrast, color vision and low-vision proofing, and flashing in animations, and exports carry the image’s description.

Export. PNG, JPEG, WebP, TIFF, TGA, PDF, SVG, OpenEXR, and layered Photoshop files at the size and quality you choose, with a preview of the file before it’s written. Export layers, comps, and artboards as separate files, and animated GIF and WebP.

Sharing a project. File > Package Project gathers a project and every file it links to into one folder or zip that opens wherever it’s moved, and lists the fonts its text uses, since those aren’t copied. Save Packaged Copy instead puts the originals inside a single project file.

Keeping your work. Undo for every change with a History panel and snapshots, autosave and crash recovery, and crash reports that stay on your machine. Your images, projects, and reports never leave it.

Installing and Updating

The download page has a setup program for Windows, which installs for you alone with no administrator needed, and an AppImage for Linux, which runs wherever you save it. ImageGui needs nothing else installed.

ImageGui keeps itself up to date. Each time it starts, it checks for a new version without making you wait and downloads one in the background. A quiet bar then says it’s ready: Restart to update installs it now, Later installs it the next time ImageGui starts, and What’s new shows what changed. ImageGui never updates while a project has unsaved changes, so Restart to update waits until you save. Your settings, presets, libraries, and autosaves are left as they are.

The check asks only for the list of versions and then for the new version itself. It sends no id, no version number, and nothing about you, your computer, or how you use ImageGui. Help > Check for Updates checks at any time. Under Updates in Preferences you can turn the check at startup off, or choose to update from Develop, every build of the next version ahead of its release, instead of Release.

Project Files

Projects are saved in format version 14, the 1.0 format. ImageGui 1.0 opens a project from any earlier version and upgrades it as it reads it. A project saved by 1.0 opens in every later release. A project saved by a later release may not open in 1.0.

License

ImageGui is free to use, for personal or commercial work, under the ImageGui Freeware License. The license and the notices for the third-party software ImageGui includes are installed beside the app, and Help > About ImageGui shows both, with the version. Copy version details there copies the version, operating system, and .NET runtime for a bug report.

Known Limitations

  • Copying and pasting images through the system clipboard has been tested headlessly, not yet against every desktop’s real clipboard.
  • AVIF, HEIF, and JPEG XL files don’t open yet. ImageGui names the format and says so.
  • OpenEXR files compressed in some ways, such as DWAA or B44, don’t open.
  • The ACES output transforms are for SDR screens. HDR displays and HDR exports come later.
  • Verifying an artboard’s export isn’t supported yet, and a PDF or SVG export is verified by its bytes alone, since ImageGui can’t read those back.
